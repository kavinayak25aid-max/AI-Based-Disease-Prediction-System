# AI-Based Disease Prediction System

A beginner-friendly, production-ready machine learning web application built with Python, Scikit-learn, and Flask that predicts potential disease categories based on user-selected symptoms.

> **IMPORTANT MEDICAL DISCLAIMER**
> This project is developed strictly for **educational and academic demonstration purposes**. 
> All predictions are generated by statistical machine learning models trained on an educational sample dataset. 
> It is **NOT** a clinical diagnostic instrument, does not provide medical advice or treatments, and should never be used as a substitute for professional healthcare consultation. Always consult a licensed medical professional for healthcare decisions.

## ⚙️ Installation & Setup (Windows)

### 1. Prerequisites
- **Python 3.10+** (Tested on Python 3.14 x64)
- **Pip** package manager

### 2. Open Terminal in Project Folder
```powershell
cd "c:\Users\Kavinaya K\OneDrive\Desktop\Major Project\AI_Disease_Prediction_System"
```

### 3. Create & Activate Virtual Environment (Recommended)
```powershell
# Create virtual environment
py -m venv venv

# Activate on Windows PowerShell
.\venv\Scripts\Activate.ps1
```
*(If PowerShell shows an execution policy error, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` first).*

### 4. Install Dependencies
```powershell
py -m pip install -r requirements.txt
```

## 🚀 Step-by-Step Execution Workflow

### Step 1: Preprocess Data (Optional - Already Generated)
```powershell
py preprocess.py
```
*Loads raw data, standardizes column headers, removes duplicates, and exports `dataset/cleaned_symptoms_disease.csv`.*

### Step 2: Train Model
```powershell
py train_model.py
```
*Trains Decision Tree and Naive Bayes models, prints comparative metrics, and saves `models/disease_model.joblib`.*

### Step 3: Run Automated Test Suite
```powershell
py -m pytest tests/ -v
```
*Executes all 15 unit and integration tests covering data loading, feature ordering, ML inference, error handlers, and route status codes.*

### Step 4: Start the Flask Application
```powershell
py app.py
```
*Starts the development server on `http://127.0.0.1:5000`.*

### Step 5: Open in Your Web Browser
Open your browser and navigate to:
```text
http://127.0.0.1:5000/
```

## 🔍 Troubleshooting Guide

1. **Port 5000 is already in use:**
    ```powershell
    # Run Flask on a different port:
    py -c "from app import app; app.run(port=5001)"
    ```
2. **Missing model files error:**
    ```powershell
    # Regenerate model artifacts:
    py train_model.py
    ```
3. **ModuleNotFoundError:**
    ```powershell
    # Ensure dependencies are installed in your active environment:
    py -m pip install -r requirements.txt
    ```

## 🛡️ Educational & Security Architecture
- **No PHI Stored:** No patient data or personal health identifiers are recorded or saved to any database.
- **Strict Feature Alignment:** Predictions construct the input feature vector using the exact order specified in `model_metadata.json`.
- **Friendly Error Handling:** 404, 500, and model missing exceptions route to `templates/error.html`.
